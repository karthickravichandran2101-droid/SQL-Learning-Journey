# 🔄 SQL Set Operators

This project demonstrates how SQL Server Set Operators can be used to combine or compare the results of multiple SELECT queries.

## 🎯 Business Scenario

A business may need to combine customer, employee, sales, or product information from different result sets.

Set Operators help SQL professionals combine or compare query results efficiently.

---

## 📚 Set Operators Covered

| # | Operator | Purpose |
|---|---|---|
| 1 | UNION | Combines results and removes duplicates |
| 2 | UNION ALL | Combines results including duplicates |
| 3 | INTERSECT | Returns common records from both queries |
| 4 | EXCEPT | Returns records from the first query that are not in the second query |
