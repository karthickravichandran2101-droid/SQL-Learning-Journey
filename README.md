# 🚀 SQL Learning Portfolio

Welcome to my **SQL Learning Portfolio**.

This repository documents my hands-on journey in learning **Microsoft SQL Server**, practicing SQL concepts, solving business-oriented problems, and maintaining execution evidence through SQL Server Management Studio (SSMS).

My approach is simple:

> **Learn → Practice → Execute → Validate → Document → Improve**

# 4️⃣ Arithmetic Operators

This project demonstrates arithmetic calculations using SQL Server.

### Operators Covered

- Addition `+`
- Subtraction `-`
- Division `/`
- Multiplication `*`
- Modulus `%`

### Business Examples

- Salary + Bonus = Total Compensation
- Salary - Deduction = Net Salary
- Sales Amount / Quantity = Unit Price
- Quantity × Unit Price = Total Sales
- Quantity % 10 = Remaining Units

# 5️⃣ Comparison Operators

This project demonstrates how SQL Server compares values and filters business data.

### Operators Covered

- Equals `=`
- Not Equals `<>`
- Greater Than `>`
- Less Than `<`
- Greater Than or Equal To `>=`
- Less Than or Equal To `<=`

### Business Examples

- Find Electronics products
- Exclude Electronics products
- Find sales greater than ₹100,000
- Find sales less than ₹100,000
- Find sales greater than or equal to ₹100,000
- Find sales less than or equal to ₹100,000

📁 [View Comparison Operators Project](./06_Comparison_Operators/)
