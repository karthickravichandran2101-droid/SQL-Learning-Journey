## 📌 1. Project Overview

This module demonstrates the practical application of **SQL Arithmetic Operators** using the Hospital Patient Management System database developed in Microsoft SQL Server.

The objective is to understand how mathematical calculations can be performed directly within SQL queries to solve everyday hospital business requirements.

Instead of learning SQL operators only through theoretical examples, this project uses hospital-related scenarios to demonstrate their practical applications.

## 🎯 2. Business Objective

To demonstrate how SQL Arithmetic Operators can support hospital operations, billing, finance and inventory management through basic mathematical calculations.

**Business Areas Covered:**
- Hospital Billing and Finance
- Patient Billing
- Medicine Inventory
- Revenue Calculations
- Operational Reporting

## 📚 3. SQL Arithmetic Operators Covered

| Operator | Name | Purpose |
|---|---|---|
| + | Addition | Adds two numerical values |
| - | Subtraction | Calculates the difference between two values |
| * | Multiplication | Calculates the product of two values |
| / | Division | Divides one value by another |
| % | Modulo | Returns the remainder after division |

## 💼 4. Real-World Hospital Business Use Cases

### 01. Addition (+) – Total Hospital Bill

**Business Requirement:**

Calculate the total patient bill by adding consultation charges, laboratory charges and medicine charges.

**Business Application:** Hospital Billing and Finance.

SQL File: [01_Addition.sql](./01_Addition.sql)

### 02. Subtraction (-) – Outstanding Bill Amount

**Business Requirement:**

Calculate the outstanding patient bill amount by subtracting the amount paid from the total bill amount.

**Business Application:** Payment Tracking and Outstanding Receivables.

SQL File: [02_Subtraction.sql](./02_Subtraction.sql)

### 03. Multiplication (*) – Medicine Inventory Valuation

**Business Requirement:**

Calculate the total inventory value by multiplying the medicine unit price by its available stock quantity.

**Business Application:** Pharmacy Inventory and Stock Valuation.

SQL File: [03_Multiplication.sql](./03_Multiplication.sql)

### 04. Division (/) – Average Billing Amount

**Business Requirement:**

Calculate the average billing amount by dividing the total billing amount by the number of bills.

**Business Application:** Hospital Finance and Management Reporting.

SQL File: [04_Division.sql](./04_Division.sql)

### 05. Modulo (%) – Remaining Quantity Calculation

**Business Requirement:**

Calculate the remainder when a quantity is divided into equal groups.

**Business Application:** Pharmacy Stock Packaging and Inventory Allocation.

SQL File: [05_Modulo.sql](./05_Modulo.sql)
