# 🧮 Arithmetic Operators – Hospital Patient Management System

## 🎯 Objective

This section demonstrates how SQL Arithmetic Operators can be used
to perform calculations on hospital operational and financial data.

Instead of learning arithmetic operators only through theoretical
examples, this project applies them to real-world hospital
business scenarios.

---

## 📚 Arithmetic Operators Covered

| Operator | Meaning | Business Application |
|----------|---------|----------------------|
| + | Addition | Calculate total cost |
| - | Subtraction | Calculate outstanding amount |
| * | Multiplication | Calculate medicine cost |
| / | Division | Calculate average cost |
| % | Modulo | Calculate remainder |

---

## 🏥 Business Scenarios

The scenarios covered in this section include:

1. Calculate total hospital charges
2. Calculate outstanding bill amount
3. Calculate total medicine cost
4. Calculate average cost
5. Demonstrate modulo operation

---

## 🧠 Learning Framework

Each operator will be explained using:

**WHAT → WHY → WHEN → HOW → BUSINESS SCENARIO → DO → RESULT → INSIGHT**
