# Numeric Functions — Execution Evidence

## Project
Hospital Patient Management System

## Module
System-Defined Functions — Numeric and Mathematical Functions

## Purpose
This folder contains screenshots documenting individual SQL Server numeric function examples.

## Evidence Inventory

| File | Function | Purpose |
|---|---|---|
| `1_ABS.PNG` | ABS() | Returns the absolute value |
| `2_ceiling.PNG` | CEILING() | Rounds upward to an integer |
| `3_FLOOR.PNG` | FLOOR() | Rounds downward to an integer |
| `4_ROUND.PNG` | ROUND() | Rounds a numeric value |
| `5_SIGN.PNG` | SIGN() | Returns the sign of a number |
| `6_POWER.PNG` | POWER() | Raises a number to a power |
| `7_SQRT.PNG` | SQRT() | Calculates a square root |
| `8_SQUARE.PNG` | SQUARE() | Calculates a square |
| `9_PI.PNG` | PI() | Returns the value of pi |

## Validation Process

1. Execute the SQL examples in SQL Server Management Studio (SSMS).
2. Review each query result.
3. Compare the output against the expected result.
4. Capture the execution evidence.
5. Maintain the screenshots alongside the SQL script.

## Notes

These screenshots are intended to document learning exercises and SQL execution results. All hospital billing examples use illustrative data rather than actual patient records.
