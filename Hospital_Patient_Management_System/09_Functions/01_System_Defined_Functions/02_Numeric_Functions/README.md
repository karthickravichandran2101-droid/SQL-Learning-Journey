# Numeric Functions — Hospital Patient Management System

## 📌 Project Overview

This module demonstrates SQL Server numeric and mathematical functions using examples inspired by a Hospital Patient Management System.

The objective is to understand how SQL functions can support numeric calculations, billing analysis, and reporting.

## 🎯 Learning Objectives

- Understand numeric and mathematical functions in SQL Server.
- Apply functions to sample hospital-related scenarios.
- Practice writing and executing SQL queries in SSMS.
- Document query outputs as project evidence.
- Build a structured SQL portfolio on GitHub.

## 🧰 Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- GitHub

## 📚 Functions Covered

| Function | Purpose |
|---|---|
| ABS() | Returns the absolute value |
| CEILING() | Returns the smallest integer greater than or equal to a number |
| FLOOR() | Returns the largest integer less than or equal to a number |
| ROUND() | Rounds a numeric value to a specified precision |
| SIGN() | Returns -1, 0, or 1 based on the input |
| POWER() | Raises a number to a specified power |
| SQRT() | Returns the square root |
| SQUARE() | Returns the square of a number |
| PI() | Returns the value of pi |

## 🏥 Business Use Case

A hospital needs to calculate patient charges, discounts, and final bill amounts. SQL numeric functions can help with calculations and reporting.

The sample billing scenario includes:

- Consultation fees
- Laboratory charges
- Medicine charges
- Discount amount
- Final bill amount

All values are illustrative.
