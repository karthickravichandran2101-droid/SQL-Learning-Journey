# 📸 String Functions — Execution Evidence

## Project
Hospital Patient Management System

## Module
SQL Server — System-Defined String Functions

## Purpose
This folder contains screenshots captured from SQL Server Management Studio (SSMS) to demonstrate the execution and results of string-function queries.

## Evidence Checklist

- [ ] UPPER() and LOWER() — Change text case
- [ ] LEN() and TRIM() — Count characters and remove spaces
- [ ] CONCAT() — Combine strings
- [ ] LEFT(), RIGHT() and SUBSTRING() — Extract characters
- [ ] REPLACE(), LTRIM() and RTRIM() — Replace text and remove spaces
