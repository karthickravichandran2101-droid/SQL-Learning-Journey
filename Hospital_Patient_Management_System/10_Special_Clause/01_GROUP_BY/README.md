# 🏥 Hospital Patient Management System

## Special Clause – GROUP BY

### 📌 Project Overview

This module demonstrates the practical implementation of the SQL GROUP BY clause using Microsoft SQL Server.

The Hospital Patient Management System is used as a real-world business scenario to understand how SQL aggregates and summarizes data.

### 🎯 Learning Objectives

- Understand the GROUP BY clause.
- Aggregate records using COUNT().
- Group records based on unique column values.
- Generate city-wise patient reports.
- Generate gender-wise patient reports.

### 🛠️ Technology Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

**Query 01 – City-wise Patient Count**

**Query 02 – Gender-wise Patient Count**
