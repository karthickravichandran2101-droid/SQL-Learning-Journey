# 🏥 Hospital Patient Management System

## 📌 Project Overview

The Hospital Patient Management System is a relational database project
developed using Microsoft SQL Server.

The project simulates the core operations of a multi-specialty hospital,
including patient registration, doctors, departments, appointments,
visits, prescriptions, laboratory investigations, billing and payments.

## 🎯 Business Objective

The objective of this project is to design and implement a centralized
database that can support hospital operational data management and
business reporting.

## 🏢 Business Case

A multi-specialty hospital wants to replace fragmented spreadsheet-based
records with a centralized relational database.

The system should help the hospital manage:

- Patient registration
- Doctors
- Departments
- Appointments
- Patient visits
- Medicines
- Prescriptions
- Laboratory tests
- Laboratory results
- Billing
- Payments
